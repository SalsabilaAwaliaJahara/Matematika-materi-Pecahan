# Soal Evaluasi Matematika Kelas V — Materi Pecahan

Repositori ini berisi paket **Soal Evaluasi Kelas V SD** mata pelajaran **Matematika** dengan materi pokok **Pecahan**, dilengkapi dengan kunci jawaban, pembahasan langkah demi langkah, pedoman penskoran, serta aplikasi kuis interaktif berbasis web.

| [`script.js`](./script.js) | Data soal, penilaian otomatis untuk Pilihan Ganda & Isian Singkat, pembahasan, serta mode guru. |

## Kisi-Kisi Materi

1. **Konsep & Perbandingan Pecahan**: pecahan senilai, menyederhanakan pecahan, membandingkan, dan mengurutkan berbagai bentuk pecahan (biasa, desimal, persen).
2. **Konversi Bentuk Pecahan**: mengubah pecahan campuran ke pecahan biasa, pecahan biasa ke desimal, dan desimal ke persen (atau sebaliknya).
3. **Operasi Hitung Penjumlahan & Pengurangan**: pecahan berpenyebut berbeda, pecahan campuran, dan bilangan desimal.
4. **Operasi Hitung Perkalian & Pembagian**: perkalian pecahan biasa dengan pecahan campuran/desimal serta pembagian pecahan dengan bilangan asli/pecahan lain.
5. **Pemecahan Masalah (Soal Cerita)**: penerapan operasi pecahan dan persen dalam konteks kehidupan sehari-hari.

## Cara Menggunakan Aplikasi Web Interaktif

1. Buka berkas `index.html` secara langsung di peramban (browser), **atau** aktifkan **GitHub Pages** pada menu **Settings → Pages** repositori ini (pilih branch `main` dan folder `/ (root)`).
2. Siswa dapat mengisi nama dan mengerjakan soal Pilihan Ganda serta Isian Singkat secara interaktif, lalu menekan tombol **Periksa Jawaban** untuk melihat skor dan pembahasan.
3. Guru dapat menggunakan tombol **Cetak Soal** untuk mencetak lembar evaluasi lengkap beserta Bagian C (Uraian), atau mengaktifkan **Mode Guru** untuk meninjau kunci jawaban dan rubrik penskoran.
